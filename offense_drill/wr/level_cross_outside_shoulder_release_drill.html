WR 摆脱与路线对抗 Drill

Drill：外接手水平对齐与攻击外侧肩膀 Release 摆脱训练 (Level Cross & Outside Shoulder Release)

训练目的： 训练外接手（WR）面对站位偏外侧的防守后卫（DB）时，如何通过垂直压迫全速斜向冲刺拉平距离（Level Cross）；在与 DB 达成水平齐平（Hip-to-Hip）瞬间，运用眼神与躯干假动作冻结 DB 内侧重心，随后通过硬刺步（Foot Jab）结合强力打手（Club）与掏穿（Rip）强行突破 DB 外侧肩膀，并迅速切回 DB 正前方（Restack）完成卡位摆脱。

场地与准备： -
在开球线前方设置 10-15 码的纵向对抗通道； -
防守后卫（DB）在起跑线前方 3-5 码处呈偏外侧站位（Outside Leverage）； -
QB 站在传球点持球准备。

流程与步态： -
阶段一（垂直压迫与水平拉平 - Level Cross & Stack Angle）： WR 爆发出步启动，保持垂直压迫速度不减且目视前方，不急于切向外侧，而是向斜外侧全速冲刺“拉平距离”。当与 DB 达到齐平（Hip-to-Hip / Leveraged）瞬间，用眼睛和躯干假装切内侧，诱骗 DB 冻结（Freeze）或向内侧收缩重心； -
阶段二（攻击外侧肩膀与手部打压 - Outside Shoulder Attack & Club/Rip）： 在与 DB 水平对齐瞬间，WR 迅速向外侧踩出硬刺步（Foot Jab），同时近侧手做强力打手（Club）拍开 DB 的阻挡伸手，远侧手向上掏穿（Rip）侧身贴紧 DB 外侧肩膀强行通过； -
阶段三（外侧路线切入与卡位身前 - Out-Route Restack）： 成功突破 DB 外侧肩膀后，严禁向外侧跑大圈。使用内侧脚低角度抓地，快速卡回 DB 正前方（Restack），将 DB 封锁在身后后再切出外侧路线（Out / Corner Route）并接球。

训练要点： -
[对齐姿态规范]： 保持垂直压迫速度不减，目视前方，不提前暴露跑动意图； -
[手脚联动对抗]： 踩出 Foot Jab 瞬间必须同步衔接强力 Club/Rip 组合手，借力剥离 DB 触碰； -
[低角度 Restack 卡位]： 突破后切忌跑弧线大圈，必须用内侧脚强力抓地快速回切卡住 DB 正前方身位，夺回路线主导权。

易错情况： -
启动后过早向外侧侧滑或跑大圈，未能在纵向上与 DB 达成齐平，导致被 DB 顺势推向边线挤出场外； -
假动作时身体减速停顿，丧失爆发冲力； -
突破后未执行 Restack 卡位，直接向外侧飘移跑动，给 DB 留出追击拍球的空间。

进阶： DB 进行实战级强度的贴身延误与手部推挤（Jam/Press），WR 必须在真实物理对抗中完成假动作诱骗、Club/Rip 突破与 Restack 强行卡位。

退阶： 慢速分解练习：1. 慢速冲刺与 DB 齐平 ➔ 2. 演练“内侧假动作 ➔ Foot Jab + Club/Rip”动作组合 ➔ 3. 慢速内侧脚抓地 Restack 步态，建立肌肉记忆。
